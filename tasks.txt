Техническое задание: Football Stats Telegram Bot
1. Цель проекта

Разработать Telegram-бота на Python, который по команде пользователя получает результаты футбольных матчей за последние 7 дней, парсит статистику с ESPN и отправляет её пользователю в удобном виде.

Проект учебный.

Основная цель — самостоятельно пройти путь:

HTTP-запрос → HTML → парсинг → Python-данные → обработка → Telegram.

2. Лиги

Бот поддерживает:

Premier League;
EFL Championship;
Serie A;
La Liga;
Bundesliga;
Ligue 1.
3. Команды Telegram
/start

Выводит описание бота и список доступных команд.

Пример:

⚽ Football Stats Bot

Результаты матчей за последние 7 дней.

/england — Premier League
/england_2 — Championship
/italy — Serie A
/spain — La Liga
/germany — Bundesliga
/france — Ligue 1
Команды лиг
/england
/england_2
/italy
/spain
/germany
/france

После команды бот должен показать завершённые матчи выбранной лиги за последние 7 дней.

Отдельные команды /score, /xg, /possession, /stat, /match в первой версии не нужны.

4. Какие матчи получать

Для выбранной лиги необходимо:

Получить страницу матчей ESPN.
Найти матчи, дата которых находится в диапазоне:
сегодня - 7 дней ≤ дата матча ≤ сегодня
Оставить только завершённые матчи со статусом FT.
Не учитывать:
будущие матчи;
live-матчи;
товарищеские матчи;
матчи других соревнований.

ESPN действительно использует FT для обозначения завершённых матчей в расписании.

5. Данные одного матча

Для каждого матча необходимо получить:

Обязательные данные
дата;
домашняя команда;
гостевая команда;
итоговый счёт;
авторы голов;
минута каждого гола;
владение мячом каждой команды;
xG каждой команды;
количество ударов каждой команды.

ESPN предоставляет на страницах матчей владение и количество ударов, а в расширенной статистике современных матчей также xG.

Ассисты

Если источник явно предоставляет автора голевой передачи:

сохранить автора ассиста.

Если информации об ассисте нет:

assist = None

Отсутствие ассиста не должно ломать программу.

6. Представление данных внутри Python

Парсер не должен сразу создавать Telegram-текст.

Результат одного матча должен представляться как структурированные Python-данные.

Логически:

match

date
home_team
away_team

home_score
away_score

home_possession
away_possession

home_xg
away_xg

home_shots
away_shots

goals

Для каждого гола:

player
team
minute
assist

Конкретную структуру данных разработчик выбирает самостоятельно.

7. Формат ответа пользователю

Пример:

🏴 Premier League
Матчи за последние 7 дней

Brentford 3:0 Tottenham

⚽ Голы:
12' Keane Lewis-Potter
33' Vitaly Janelt
49' Michael Kayode

📊 Статистика:
Владение: 41% — 59%
xG: 3.96 — 0.47
Удары: 26 — 9

────────────

Fulham 1:1 Manchester United

⚽ Голы:
58' Rodrigo Muniz (автогол)
73' Emile Smith Rowe

📊 Статистика:
Владение: 52.4% — 47.6%
Удары: 13 — 10

Фактические показатели в примере соответствуют страницам ESPN для этих матчей.

Если информации о показателе нет:

xG: нет данных

Бот не должен падать из-за отсутствующего значения.

8. Логика программы

Основной поток данных:

Telegram-команда
        ↓
определение выбранной лиги
        ↓
получение страницы ESPN
        ↓
поиск матчей за последние 7 дней
        ↓
отбор матчей FT
        ↓
получение ссылки каждого матча
        ↓
парсинг страницы матча
        ↓
создание Python-данных
        ↓
форматирование
        ↓
отправка в Telegram
9. Сопоставление команд и лиг

Не создавать отдельный парсер для каждой страны.

Должно существовать одно сопоставление:

england    → Premier League
england_2  → Championship
italy      → Serie A
spain      → La Liga
germany    → Bundesliga
france     → Ligue 1

Один и тот же код парсинга должен использоваться для всех поддерживаемых лиг.

Aiogram позволяет обрабатывать Telegram-команды через Command filter; сами команды могут содержать строчные английские буквы, цифры и _, поэтому /england_2 является допустимым названием.

12. Обработка ошибок

Минимально предусмотреть следующие случаи.

ESPN недоступен

Бот отвечает:

Не удалось получить данные. Попробуйте позже.
За последние 7 дней матчей нет
За последние 7 дней завершённых матчей не найдено.
У конкретного матча нет xG или другой статистики
xG: нет данных

Программа продолжает работу.

Один матч не удалось распарсить

Ошибка одного матча не должна уничтожать результаты остальных матчей.

13. Telegram-сообщения

Если все матчи не помещаются в одно Telegram-сообщение:

разделить результат на несколько сообщений;
не обрезать матч посередине.
14. Порядок разработки

Разрабатывать проект последовательно.

Этап 1

Один URL завершённого матча:

URL
↓
команды + счёт
Этап 2

Добавить:

владение
удары
xG
Этап 3

Добавить:

авторов голов
минуты голов
ассисты, если доступны
Этап 4

Получить со страницы одной лиги список завершённых матчей.

Этап 5

Оставить только матчи последних 7 дней.

Этап 6

Для каждого найденного матча получить полную статистику.

Этап 7

Подключить /england.

Этап 8

Добавить остальные пять лиг через общую логику.

Этап 9

Добавить /start.

Этап 10

Обработать основные ошибки и проверить весь проект.

16. Критерии готовности

Проект считается законченным, если:

/start работает.
Все шесть команд лиг работают.
Бот получает данные с ESPN.
Выбираются только завершённые матчи последних 7 дней.
Для каждого матча выводятся:
команды;
счёт;
голы;
владение;
xG;
удары.
Отсутствующая статистика не вызывает падение программы.
Ошибка одного матча не ломает остальные результаты.
Общая логика парсинга не продублирована для каждой лиги.
Telegram-токен не находится в исходном коде.
Проект можно запустить командой из README и получить рабочий результат.
Результат проекта

Пользователь пишет:

/italy

и получает статистику всех завершённых матчей Serie A за последние 7 дней.

Именно это является конечным результатом первой версии.
