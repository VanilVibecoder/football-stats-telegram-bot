# Telegram Stars для подписки внутри Telegram

Цифровой Pro-доступ внутри Telegram продаётся только за Stars, с ledger, refund и support flow. Независимый сайт сможет использовать СБП/T-Pay/карты позже, но не как обход Telegram; платный запуск блокируется, пока владелец не проверит фактическую цену покупки и вывод Stars через Fragment.
