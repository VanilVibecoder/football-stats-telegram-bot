# Telegram-first SaaS с независимым backend

Первым клиентом остаётся Telegram, потому что там находится стартовая аудитория и можно быстрее проверить ценность. Бизнес-правила и данные не связываются с aiogram: сайт или Mini App смогут использовать те же application services, но появятся только после измеренного спроса.
