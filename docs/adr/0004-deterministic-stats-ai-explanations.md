# Детерминированные расчёты, AI только для объяснения

Python и SQL вычисляют каждое число, выборку и confidence input; LLM получает готовые facts/evidence и превращает их в короткое объяснение. Это дороже по инженерному времени, чем свободный AI-ответ, но делает результаты проверяемыми и не превращает частоту в выдуманную вероятность.
