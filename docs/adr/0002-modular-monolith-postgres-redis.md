# Модульный монолит, PostgreSQL как источник истины

Продукт разворачивается одним Python-приложением с внутренними границами, PostgreSQL хранит постоянное состояние, а Redis — только временный кэш, locks, limits и dedupe. Это минимизирует эксплуатационные расходы solo-founder и не допускает потери знаний или оплат при очистке Redis.
